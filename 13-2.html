📖 什么是 SVG 图标

Lucide 是一套开源的描边风格图标，每枚图标本质上是一小段 SVG 代码。 页面里先写占位符 <i data-lucide="house"></i>， 引入本地的 cdn/lucide/lucide.min.js 后执行 lucide.createIcons()， 脚本会把每个占位符替换成真正的 <svg> 元素（路径使用 stroke="currentColor"），因此颜色、粗细、尺寸都能用 CSS 直接控制，且无级缩放不模糊。

<!-- 写法：占位符 --> <i data-lucide="house"></i> <!-- 页面底部引入本地文件并渲染 --> <script src="cdn/lucide/lucide.min.js"></script> <script> lucide.createIcons({ icons: lucide.icons }); </script> <!-- 渲染之后得到的 SVG（以 house 为例） --> <svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"> <path d="M15 21v-8a1 1 0 0 0-1-1h-4a1 1 0 0 0-1 1v8" /> <path d="M3 10a2 2 0 0 1 .709-1.528l7-5.999a2 2 0 0 1 2.582 0l7 5.999A2 2 0 0 1 21 10v9a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2z" /> </svg>
  • 脚本：cdn/lucide/lucide.min.js（下载自 unpkg，v0.460.0）
  • 静态图标文件：cdn/lucide/icons/*.svg（下载自 lucide-static）
  • 引用方式：<script src="cdn/lucide/lucide.min.js"></script>

📄 静态 SVG 文件（<img> 引用）

除了用脚本把图标内联进页面，也可以把下载好的 .svg 文件当图片直接引用。 注意：作为 <img> 时 currentColor 没有上下文、会变成黑色， 想跟随文字变色就需要把 SVG 内容内联（像上面 createIcons 生成的那样）。
