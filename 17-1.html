JSON —— JavaScript Object Notation

轻量级数据交换格式：独立于语言、键必须双引号、方法只有 parse 和 stringify

1

JSON 语法规则

JSON 由「键值对」组成，键和字符串值都必须用双引号；值可以是字符串、数字、布尔、null、数组、对象，不支持函数和 undefined。

{ "name": "张语桐", "age": 20, "isStudent": true, "hobbies": ["读书", "网页设计"], "address": { "city": "北京", "zip": "100000" }, "remark": null }
对比项JSONJS 对象字面量
键（key）必须双引号 "name"可省略引号 name
字符串值只能双引号单、双引号皆可
函数 / undefined不允许允许
末尾逗号不允许允许（新引擎）
2

JSON.stringify 与 JSON.parse

stringify：JS 对象 → JSON 字符串（发给服务器前）；parse：JSON 字符串 → JS 对象（收到响应后）。 

const zyt_obj = {
  name: '张语桐',
  age: 20,
  greet: function () { return 'hi'; }
};

// 对象 → JSON 字符串（函数被丢弃）
const zyt_json =
  JSON.stringify(zyt_obj);

// JSON 字符串 → 对象
const zyt_back =
  JSON.parse(zyt_json);
