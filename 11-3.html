第11章练习3 - 使用 @keyframes 关键帧与 animation 属性制作动画

📖 一、CSS3 动画语法

/* 1. 用 @keyframes 定义关键帧 */
@keyframes zyt_move {
  0%   { left: 0; }
  50%  { background: pink; }
  100% { left: 100%; }
}

/* 2. 在选择器上应用动画（简写） */
.zyt_box { animation: zyt_move 3s ease-in-out 0s infinite alternate forwards; }

animation-name

绑定的 @keyframes 名称，多个用逗号分隔。

animation-duration

完成一次动画的时长，如 3s、500ms。

animation-timing-function

速度曲线：linear、ease、ease-in、ease-out、ease-in-out、cubic-bezier()。

animation-delay

动画开始前的等待时间，可为负值（直接跳到中途）。

animation-iteration-count

播放次数，数字或 infinite（无限循环）。

animation-direction

播放方向：normal、reverse、alternate、alternate-reverse。

animation-fill-mode

结束后保留状态：forwards、backwards、both；默认 none（回到初始）。

animation-play-state

运行状态：running、paused，可配合 :hover 做暂停交互。

🎛️ 四、播放控制：direction / delay / fill-mode / play-state

1. animation-direction 四种模式（蓝→红 单向渐变）

normal：始终正向
reverse：始终反向
alternate：正→反 往返
alternate-reverse：反→正

2. animation-delay + fill-mode: both（延迟 1 秒后才开始生长）

延迟 1s 启动，启动前保持 0 宽度（fill-mode: both）
对比：无 delay，立即从 0 生长到 100%（forwards）

📋 六、animation 简写属性速查

顺序 属性 常用值 默认值
1 animation-name @keyframes 名称 none
2 animation-duration 3s / 500ms 0s（不播放）
3 animation-timing-function linear / ease / ease-in-out / cubic-bezier() ease
4 animation-delay 1s / -0.5s 0s
5 animation-iteration-count 3 / infinite 1
6 animation-direction normal / reverse / alternate / alternate-reverse normal
7 animation-fill-mode none / forwards / backwards / both none
8 animation-play-state running / paused running
💡 小技巧：①简写时 duration 必须写在 delay 前面，顺序反了会被当成 delay；②动画只改 transform / opacity 最流畅（GPU 加速），避免频繁改 width/left；③只改一个属性时可以写 from / to 代替百分比。
