📖 一、3D 动画三件套

/* 1. 父元素开透视（近大远小的景深） */
perspective: 800px; /* 默认 none = 平行投影，没有立体感 */

/* 2. 父容器声明"子元素保留 3D 空间"（否则子元素会被压平成 2D） */
transform-style: preserve-3d;

/* 3. 子元素做 3D 变换并串起来 */
transform: rotateY(45deg) translateZ(100px);

perspective

透视距离（观察点到 z=0 平面的距离）。值越小透视越夸张，none 则无景深。

perspective-origin

观察点位置，默认 50% 50%（正中）。改成角落能模拟仰视/俯视视角。

transform-style: preserve-3d

让子元素在同一 3D 空间里叠加，而不是各自被压平。3D 结构的必备属性。

backface-visibility

背面是否可见：hidden 时元素转到背面就"消失"，翻转卡片靠它避免镜像穿帮。

坐标轴：rotateX（左右翻）/ rotateY（水平门轴）/ rotateZ（平面转）/ rotate3d（任意轴）

rotateX

绕 X 轴（红）

rotateY

绕 Y 轴（绿）

rotateZ

绕 Z 轴（蓝）

rotate3d

轴 (1,1,0) 斜转

📋 六、3D 属性速查表

属性 / 函数 作用 常用值 默认值
perspective 父元素设置景深 500px / 800px / none none
perspective-origin 观察点位置 50% 50% / 20% 0% 50% 50%
transform-style 子元素是否保留 3D 空间 preserve-3d / flat flat
backface-visibility 背面是否可见 hidden / visible visible
translateZ / translate3d 沿 Z 轴前后移动 translateZ(100px) 0
rotateX / rotateY / rotateZ 绕三轴旋转 rotateY(180deg) 0
rotate3d 绕任意轴旋转 rotate3d(1, 1, 0, 45deg) 0
scale3d 三轴缩放 scale3d(1, 1, 2) 1
💡 避坑指南：①父容器忘了写 preserve-3d，子元素会被压平，立体结构瞬间变 2D；②不要在 3D 容器上加 overflow: hidden、filter、opacity < 1——浏览器会强制把该层压平（会生成新的层叠上下文）；③perspective 写在直接父元素上才生效；④拼立方体时 face 尺寸的一半就是 translateZ 的距离。
