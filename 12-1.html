🎨 12-1 CSS变量（自定义属性）

第12章练习1 - 用 -- 定义变量、用 var() 读取变量，一处修改、全页生效

📘 一、什么是CSS变量

CSS变量又称"自定义属性"，必须以 -- 开头，通过 var() 函数使用；常定义在 :root 上实现全页共享。

/* 1. 定义：属性名必须以 -- 开头 */
:root {
  --zyt_primary: #4a90e2;/* 颜色变量 */
  --zyt_radius: 10px;/* 尺寸变量 */
}
/* 2. 使用：var(变量名) */
.zyt_card { border-radius: var(--zyt_radius); color: var(--zyt_primary); }

📍 三、作用域与就近覆盖

变量和普通CSS属性一样遵循就近原则：子元素/局部类里重新定义后，只覆盖该元素上的值。

① 全局（继承自 :root）

主题蓝 #4a90e2 未覆盖，用全局值

② 局部（.zyt_scope_local 重新定义为红色）

局部红 #d9534f 只影响这个容器内部
.zyt_scope_local { --zyt_primary: #d9534f; }/* 只在该容器内生效 */
/* 容器外的元素仍然是 :root 的 #4a90e2 */

🛡️ 四、var() 默认值（回退值）

语法：var(变量, 默认值)。变量未定义时使用默认值——左边卡片用了默认值，右边卡片的变量已在 :root 定义。

未定义变量 → 用默认值

background-color: var(--zyt_undefined_color, #888)
结果：显示灰色 #888

已定义变量 → 用变量值

background-color: var(--zyt_primary)
结果：显示主题色 #4a90e2

🎭 五、综合应用：一键主题换肤

JS 只负责给 <html> 换 data 属性，颜色全部由CSS变量切换——这正是变量最大的价值。

🎨 换肤效果预览卡片

标题色、背景色、左边框、按钮颜色都取自 --zyt_primary 系列变量，切换主题时整体同步变化（含 0.4s 过渡动画）。

/* CSS：按 html 上的属性切换整套变量 */
[data-zyt-theme="green"] { --zyt_primary: #2eb872; --zyt_primary_light: #e6f9f0; }
/* JS：只换属性，不碰任何颜色 */
var zyt_theme = "green";
document.documentElement.setAttribute("data-zyt-theme", zyt_theme);

📋 七、实现要点回顾

--前缀

自定义属性必须以两个短横线开头，否则是普通属性；本页统一用 --zyt_ 前缀避免冲突。

var() 读取

只在属性值位置使用，如 color: var(--zyt_primary)；还可写 var(--zyt_c, #ccc) 提供默认值。

:root 挂载

定义在 :root 上全页继承；定义在某个类上则只对该类及其子元素生效（就近覆盖）。

变量可变

变量是运行时值，可用 JS 的 setProperty 或切换 class / data 属性整体换肤、联动缩放。

calc 搭配

变量可参与 calc() 四则运算，实现"一个滑块控制全页尺寸"这类联动效果。

过渡动画

变量本身不支持 transition，但使用它的属性（color、background 等）可以正常过渡。

💡 小技巧：①变量名建议小写加中划线并带项目前缀（如 --zyt_primary）；②变量值可以是颜色、长度、字体栈甚至整段 transform；③给元素加 transition 后，换肤时颜色会平滑渐变，观感更好。
