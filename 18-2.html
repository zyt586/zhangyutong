🏬 电商全站系统架构图

Canvas 绘制 · 六层架构 · 光点沿链路流动表示请求/数据的流转，鼠标悬停可高亮各层

📐 架构说明
  • 用户层：PC 网页 / 移动 App / 微信小程序 / H5，多端接入；
  • 接入层：CDN 静态加速 → Nginx 负载均衡 → API 网关（鉴权/限流/路由）；
  • 应用服务层：用户、商品、订单、支付、库存、搜索推荐等微服务，可独立部署扩容；
  • 中间件层：Redis 缓存热点数据、消息队列削峰填谷、Elasticsearch 商品检索；
  • 数据层：MySQL 主从读写分离、OSS 对象存储商品图片、大数据分析报表；
  • 外部服务：第三方支付（微信/支付宝）、物流、短信验证；
  • 动画中的光点表示一次下单请求自上而下贯穿各层，橙点为请求、绿点为数据返回。
