📐 Web前端的长度单位

第11章练习1 - CSS 中常用长度单位的分类与演示（绝对单位 / 相对单位）

📏 一、绝对单位（固定大小，不随环境变化）

px 像素

最常用的单位，1px = 1/96 英寸。屏幕上的固定尺寸，网页布局的首选。

cm / mm / in 厘米/毫米/英寸

物理长度单位，1in = 2.54cm = 25.4mm，多用于打印样式。

pt / pc 磅/派卡

印刷行业单位，1pt = 1/72 英寸，1pc = 12pt，常见于 Word、字号设置。

演示：px 的固定宽度（拖动浏览器窗口大小不会改变）

width: 100px
width: 200px
width: 300px

🔄 二、相对单位（相对于某个参照物）

% 百分比

相对于父元素的对应尺寸，常用于流式布局、宽度自适应。

em 相对当前字号

相对于当前元素自身的 font-size，层层继承，适合内距和缩进。

rem 相对根字号

只相对于根元素 <html> 的 font-size，不受父级影响，适合整体缩放。

vw / vh 视口宽/高

1vw = 视口宽度的 1%，1vh = 视口高度的 1%，适合大屏展示、满屏布局。

vmin / vmax 视口小/大边

vmin 取宽高中较小者，vmax 取较大者，横竖屏切换时很实用。

ch / ex 字符宽度

ch = 数字 "0" 的宽度，ex = 小写字母 x 的高度，适合控制每行字数。

fr 弹性比例

仅用于 Grid 网格布局，表示剩余空间的分配比例（如 1fr 2fr）。

rem vs em 怎么选？

em 会随父级字号层层放大易失控；rem 只认根字号，响应式更可控。

演示：% 相对于父元素（父容器宽 400px）

width: 25% = 100px
width: 50% = 200px
width: 75% = 300px
width: 100% = 撑满父容器

演示：em 相对于当前元素的 font-size（文字越大，em 换算出的长度越大）

父容器 font-size: 16px → 1em = 16px（这一行本身是 16px）

这一行 font-size: 24px → 1em = 24px，段落缩进 text-indent: 2em

10em × 4em（字号 20px → 200px × 80px）

演示：vw / vh 相对于浏览器视口（改变窗口大小试试！）

width: 25vw（视口宽度的 25%）
width: 50vw（视口宽度的 50%）

width: 30ex —— 与小写字母 x 的高度相关（左边界橙色）

📋 三、单位速查表

单位 类型 参照物 典型场景
px 绝对 无 边框、阴影、固定尺寸
cm/mm/in/pt/pc 绝对 物理长度 打印样式、印刷排版
% 相对 父元素 流式布局、宽度自适应
em 相对 当前元素字号 内距、缩进、组件内部比例
rem 相对 根元素 html 字号 响应式字号、整体缩放
vw/vh 相对 视口宽/高 满屏布局、大屏展示
vmin/vmax 相对 视口小/大边 横竖屏自适应
ch/ex 相对 字符 0 宽 / x 高 控制每行字数、阅读排版
fr 相对 Grid 剩余空间 CSS Grid 网格分栏
💡 小技巧：日常写页面优先用 px 做细节、%/vw 做布局、rem 做响应式字号；避免在嵌套结构里滥用 em，否则字号会层层放大。
