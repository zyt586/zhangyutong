🎠 一、圆柱旋转画廊（img/10.jpg ~ 21.jpg，12 张）

12 张图片绕 Y 轴均匀排成圆柱（每张 rotateY 相差 30°），整体自动旋转；悬停暂停，点住某张卡片会向你"走近"。

hover 暂停 + 卡片前移 →
/* 圆柱半径公式：r = (卡片宽 ÷ 2) ÷ tan(180° ÷ 张数) */
/* 12 张：r = 75 ÷ tan(15°) ≈ 280px，取 290px 留缝隙 */
.zyt_cyl_card { transform: rotateY(var(--zyt_a)) translateZ(290px); }

🏠 二、3D 房间画廊（img/22.jpg ~ 29.jpg，8 张）

后墙 4 张（2×2）、左右墙各 1 张、地板和天花板各 1 张，围成一个敞口房间；视角自动缓慢摇摆，悬停暂停。

hover 定格视角 →
/* 房间 300×200×200（半：150 / 100 / 100），敞口朝向观众 */
.zyt_wall_back    { transform: translateZ(-100px); }
.zyt_wall_left    { transform: rotateY(-90deg) translateZ(150px); }
.zyt_wall_right   { transform: rotateY(90deg) translateZ(150px); }
.zyt_wall_floor   { transform: rotateX(-90deg) translateZ(100px); }
.zyt_wall_ceiling { transform: rotateX(90deg) translateZ(100px); }

📋 四、实现要点回顾

透视放舞台

perspective 写在最外层舞台（stage）上，整个场景才有统一景深。

preserve-3d 放容器

圆柱、房间这些"装配体"必须 transform-style: preserve-3d，否则子元素被压平。

--zyt_a 自定义属性

每张卡片只存自己的角度，hover 时只需改 translateZ 就能向前移动，不用重复写整串 transform。

backface-visibility

圆柱背面的图片和翻转卡背面自动隐藏，转过去不穿帮、不显示镜像。

💡 小技巧：①图片统一 object-fit: cover，无论原图比例如何都能填满卡片不变形；②圆柱张数变化时用公式重算半径即可（如 16 张 → r = 75 ÷ tan(11.25°) ≈ 377px）；③3D 容器上不要加 overflow: hidden / filter，会被强制压平——裁剪要留给外层舞台做。
