⏱ JavaScript 两种定时器

setTimeout 一次性定时器 · setInterval 循环定时器 —— 用 clearTimeout / clearInterval 停止

1

setTimeout —— 等到时间后只执行一次

用 clearTimeout(id) 取消 
// 返回一个定时器编号，可传给 clearTimeout 取消
const zyt_timerId = setTimeout(() => {
  console.log('3 秒后我只执行这一次');
}, 3000);

// clearTimeout(zyt_timerId);  ← 在 3 秒内调用则不会执行

setInterval —— 每隔一段时间反复执行

用 clearInterval(id) 停止 
// 每 1000 毫秒执行一次，直到 clearInterval
const zyt_loopId = setInterval(() => {
  console.log('这是第 n 次执行');
}, 1000);

// clearInterval(zyt_loopId);  ← 停止循环
