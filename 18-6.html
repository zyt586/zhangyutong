一、智能客服在线服务流程图
用户咨询 → 问题理解 → 知识检索 → 置信度决策 → 答案/转人工 → 语料沉淀 → 离线更新闭环
flowchart TD
    U([用户发起咨询]) --> N[NLU 问题理解
意图识别 · 实体抽取]
    N --> R[知识库多路召回
向量检索 + BM25]
    R --> RR[Cross-Encoder 重排序]
    RR --> C{Top-1 置信度 >= 0.8 ?}
    C -->|是| G[NLG 生成答案
附知识溯源引用]
    C -->|否| H[转人工坐席
排队 · 分配]
    G --> S[会话记录入库]
    H --> S
    S --> A[人工标注语料]
    A --> T[离线增量训练
LoRA / SFT 微调]
    T --> K[(知识库更新
FAQ / 文档 / 图谱)]
    K -. 热加载 .-> R
    K -. 模型热更新 .-> N
二、智能客服系统数据库 ER 图
核心实体：用户、会话、消息、意图、知识条目、评价 —— 描述消息命中意图与引用知识的关联
erDiagram
    USER ||--o{ SESSION : "发起"
    SESSION ||--|{ MESSAGE : "包含"
    MESSAGE }o--|| INTENT : "命中"
    MESSAGE }o--o{ KNOWLEDGE : "引用"
    KNOWLEDGE }o--|| CATEGORY : "归属"
    MESSAGE ||--o| FEEDBACK : "获得"
    USER ||--o{ FEEDBACK : "评价"

    USER {
        bigint user_id PK "用户ID"
        varchar nickname "昵称"
        varchar channel "注册渠道"
        datetime created_at "注册时间"
    }
    SESSION {
        bigint session_id PK "会话ID"
        bigint user_id FK "所属用户"
        varchar status "进行中/已结束"
        datetime started_at "开始时间"
    }
    MESSAGE {
        bigint message_id PK "消息ID"
        bigint session_id FK "所属会话"
        varchar role "user/bot/agent"
        text content "消息内容"
        float confidence "检索置信度"
        tinyint is_transfer "是否转人工"
    }
    INTENT {
        bigint intent_id PK "意图ID"
        varchar intent_name "意图名称"
        float threshold "置信度阈值"
    }
    KNOWLEDGE {
        bigint kb_id PK "知识ID"
        varchar title "标题"
        text answer "标准答案"
        vector embedding "语义向量"
        datetime updated_at "更新时间"
    }
    CATEGORY {
        bigint category_id PK "分类ID"
        varchar category_name "分类名称"
    }
    FEEDBACK {
        bigint feedback_id PK "评价ID"
        bigint message_id FK "关联消息"
        tinyint score "满意度1-5"
        text comment "补充意见"
    }
